# Проверка сохранённого оформления и функций задания

Проверено на отдельном сервере: реальная отправка включена на 127.0.0.1:8898; браузерные отправки проверяются только на 127.0.0.1:8899 с --dry-run или с подменой ответа API. Основная рабочая папка и действующий сервер сайта не изменяются.

- Сохранены оригинальный 3D-портал (проверено состояние scene-ready), шапка, фотографии, 20 обложек каталога и структура пяти страниц.
- На ширинах 375, 768 и 1440 px нет горизонтального переполнения и сломанных изображений. Удалены добавленные ранее секции и дополнительные строки шапки.
- Поиск и жанр работают совместно; есть число результатов, пустое состояние и сброс. Карточки создаются общей функцией, сохраняя исходный вид. Выбор игры переходит к соответствующему пожеланию формы.
- Существующая форма проверяет обязательные поля, вместимость, даты/время и тарифные сочетания. Первый неверный ввод получает фокус. Проверены расчёт, подтверждение ответа API, контакты вне хранилища, редактирование, перезагрузка и удаление локальной копии.
- Корзина встроена в прежнюю раскрываемую справку пакетов: +/−, удалить, очистить, количество и сумма, отключение подтверждения пустой корзины, сводка с демонстрационным номером, применение пакета к плану.
- Прежний мобильный шаг проверки сводки сохраняется. Результат появляется после отдельного подтверждения.
- Старые адреса перенаправляются в прежние разделы. Ошибок консоли нет. Данные формы передаются только API тестового сервера; сухой режим не обращается к Telegram. Браузерный тест отказывается отправлять заявки на сервер с mode=live.

Команды: node --test tests/test_packages.cjs (26 проверок), python tests/check_coursework.py (13 HTML/CSS), python -m unittest discover -s tests -p test_booking_server.py -v (22 проверки), node tests/coursework-browser.cjs и node tests/booking-delivery-browser.cjs (установленный Playwright/Chromium, сервер --dry-run на 8899). NODE_PATH указывает на существующий комплект зависимостей; тест не устанавливает пакеты. Скриншоты находятся во временной папке pixel-original-qa.

Проверены состояние «Отправляем…», блокировка повторного нажатия, отказ доставки без ложного успеха, сохранение введённых контактов при ошибке, фокус сообщения, повтор с тем же идентификатором, подтверждённый ответ sent, отсутствие контактов в localStorage/sessionStorage, предупреждение, что удаление локальной копии не отменяет заявку, и отключение отправки при недоступном API. Серверные проверки подменяют отправителя: проверяют состав сообщения, расчёт по текущему каталогу, дубли, одновременные запросы, неопределённый результат, Origin и недоступность приватных файлов.

Для заполненных приватных настроек выполнены только getMe/getChat: бот и получатель доступны. Реальная отправка активна, API возвращает available=true и mode=live; тестовых сообщений администратору не отправляли. Полный приём сообщения в Telegram проверяется следующей настоящей заявкой пользователя.

Проверка freeze сравнивает HTML/CSS с контрольными суммами tests/site_baseline.json. Стили и исходные изображения сохранены. Устройства эмулированы в Chromium; физические телефоны и скринридер отдельно не проверялись.

## Нативный портал

Заменён только графический движок: нативные WebGL-буферы, матрицы и шейдеры используют геометрию исходной сцены, прежнее фото и запечённые карты материалов. Карты подготовлены для телефона, планшета, обычного и широкого экрана и загружаются по необходимости. Набор ресурсов — около 2.4 МБ на все четыре варианта; странице нужен один вариант. Движение сохраняет прежние углы, приближение, сглаживание и ограничения частоты/плотности пикселей. Световые вариации материалов запечены; это ограниченная сцена, не универсальный графический движок.

Удалены importmap и файлы прежнего графического движка из публичной папки. Проверка freeze допускает только документированное удаление этой служебной настройки скрипта дополнительно к прежним подключениям; CSS и интерфейсная HTML-разметка не меняются.

node tests/portal-browser.cjs: проверены четыре размера экрана, клавиатурная пауза/продолжение, неподвижность кадра при паузе и reduced motion, реакция на курсор и прокрутку, потеря/восстановление WebGL и резервная фотография. Сетевые запросы к старой библиотеке и ошибки консоли отсутствуют. Скриншоты — временная папка pixel-native-portal-qa. Положение рам и композиция сравнены с кадрами исходной сцены; небольшие отличия бликов возможны из-за замены динамического расчёта материала запечёнными картами.
