# PIXEL — отдельная версия задания

Сохранены прежнее оформление, 3D-портал, фотографии, карточки с обложками и форма визита. Требования добавлены в существующие каталог, расчёт и раскрываемый список пакетов, без новых секций и изменений CSS.

Запуск из корня рабочей копии: python booking_server.py --port 8898
Адрес: http://127.0.0.1:8898/index.html

Кнопка «Забронировать» передаёт имя, телефон и детали визита администратору через сервер. Подтверждение показывается после успешной доставки в Telegram; места подтверждает администратор. Контакты не сохраняются в браузере и базе сервера. Настройки хранятся в env/.env за пределами публичной папки; инструкция — TELEGRAM_SETUP.md в корне. Для проверки без сообщений: python booking_server.py --dry-run --port 8899. Основная версия сайта остаётся отдельно.

Обоснование основы, Functionality Plan и проверки находятся в корневом README.

Портал больше не использует сторонний JavaScript: геометрия исходных шести рам хранится в assets/portal/scene.json, освещение металла — в WebP-картах, выбираемых по пропорциям экрана. Отрисовка, перспектива, реакция на курсор, приближение при прокрутке, отражение пола, пауза и восстановление контекста выполняются нативным WebGL. Исходные HTML-элементы и CSS сохранены.

Дополнительная проверка: node tests/portal-browser.cjs. Она проверяет 375/768/1440/1920 px, неподвижность при reduced motion и паузе, реакцию геометрии на курсор/прокрутку, потерю/восстановление контекста, фото при недоступном WebGL и отсутствие загрузок удалённой библиотеки.
