# PIXEL — 4_6

Сайт компьютерного клуба PIXEL: информация о клубе и залах, каталог игр, расчёт стоимости посещения и отправка заявок администратору в Telegram.

## Функционал

- Каталог игр с поиском по названию и фильтром по жанру.
- Перенос выбранной игры в форму посещения.
- Выбор зала, ПК, даты, времени и количества игроков.
- Расчёт длительности и стоимости посещения по почасовым и пакетным тарифам.
- Корзина пакетов: добавление, изменение количества, удаление и расчёт общей суммы.
- Проверка данных формы, сводка визита и отправка заявки администратору в Telegram. Места подтверждает администратор.
- Сохранение выбранных пакетов и параметров визита между страницами.
- Информация о залах и ответы на частые вопросы.

## Запуск

Требуется Python 3.10 или новее. Установка сторонних зависимостей не нужна.

1. Склонируйте репозиторий и перейдите в его папку:

   ```powershell
   git clone https://github.com/anuarmaksut711-dotcom/4_6.git
   cd 4_6
   ```

2. Создайте файл `env/.env` по шаблону `.env.example`. Укажите `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` и `PUBLIC_ORIGIN=http://127.0.0.1:8898`. Инструкция подключения бота — [TELEGRAM_SETUP.md](TELEGRAM_SETUP.md).

3. Запустите сервер из корня проекта:

   ```powershell
   python booking_server.py --port 8898
   ```

4. Откройте [http://127.0.0.1:8898/index.html](http://127.0.0.1:8898/index.html).
